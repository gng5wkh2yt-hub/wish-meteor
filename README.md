# 许愿 · 所愿皆所成

一个安静的许愿页。写下愿望，看它化作流星划过夜空，再落成一颗留得住的玻璃气泡。

## 玩法

- 在底部输入框写下愿望，点「放飞」
- 愿望化作一颗**暖金色流星**，斜穿整片天空
- 流星飞过后，愿望落到底部，凝成一枚**液态玻璃气泡**（带许愿时间）
- 点击底部气泡堆可展开全部愿望，每个都能单独删除
- **长按星空背景** —— 流星雨会变密、变快

## 特点

- **单文件、零依赖** —— 整个应用就是一个 `index.html`，没有构建步骤
- **无后端** —— 愿望存在浏览器本地（`localStorage`），不上传任何服务器
- **认得你的设备** —— 同一设备再次打开，许过的愿望都还在

## 部署

把 `index.html` 丢到任意静态托管即可（GitHub Pages / Vercel / Netlify）。

## 一点说明

愿望只保存在你自己的浏览器里。清除浏览器数据、或换个浏览器打开，记录就没了 —— 这是"无后端"的代价，也是"你的心事不上传"的保证。
